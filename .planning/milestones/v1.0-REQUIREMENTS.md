## Functional Requirements

### FR-1: Fund Registry (Config-Driven)
- [x] **FR-1.1**: A `config/funds.json` file defines all tracked funds with: id, amc, name, type, source_page URL, section matching rules, parser type, name aliases, and significant_change threshold.
- [x] **FR-1.2**: Adding a new fund requires only adding a JSON entry (plus a custom parser only if the AMC layout is genuinely different).
- [x] **FR-1.3**: Non-equity funds (e.g., Liquid) can be listed but are skipped by the pipeline when `type != "equity"`.

### FR-2: Scraper
- [x] **FR-2.1**: Use plain HTTP (`requests` + `BeautifulSoup`) to scrape the AMC's factsheet download page. No Playwright needed.
- [x] **FR-2.2**: Detect the reporting month from the link text or file contents, not from the download date.
- [x] **FR-2.3**: Idempotent: if `data/{fund}/{YYYY-MM}.json` already exists, skip that month.
- [x] **FR-2.4**: Store the source URL and a SHA-256 hash of the downloaded file in the snapshot.
- [x] **FR-2.5**: Polite scraping: set a User-Agent header, add retries with exponential backoff, fetch only what's needed.
- [x] **FR-2.6**: Prefer the "Detailed Portfolio Disclosure" Excel file when available; fall back to the PDF factsheet.

### FR-3: Parser
- [x] **FR-3.1**: Excel parser (primary for PPFAS): Read XLS with pandas/openpyxl, identify fund sheet/section, sort by weight, extract top 10 with: rank, name, ISIN, sector, weight_pct.
- [x] **FR-3.2**: PDF text parser (fallback): Use pdfplumber to extract tables. Locate the correct fund section via `section_keyword`. Extract top 10 holdings.
- [x] **FR-3.3**: OCR fallback: Behind a flag, used ONLY if a PDF has no text layer.
- [x] **FR-3.4**: Extract AMC commentary text if present (stored verbatim as `amc_commentary`).

### FR-4: Validation
- [x] **FR-4.1**: Exactly 10 holdings extracted.
- [x] **FR-4.2**: All weights are numbers between 0 and 30 (percentage points).
- [x] **FR-4.3**: Ranks are consistent with descending weight order.
- [x] **FR-4.4**: Sum of 10 weights matches AMC-stated "top 10 total" within ±0.1pp (when that statement exists).
- [x] **FR-4.5**: Names are normalized (case, "Ltd/Limited", "&/and", punctuation) and mapped through `aliases`.
- [x] **FR-4.6**: Prefer ISIN as canonical key when available; otherwise use normalized name.
- [x] **FR-4.7**: On validation failure: do NOT commit a snapshot. Fail the workflow loudly with reason.

### FR-5: Snapshot Schema
- [x] **FR-5.1**: Schema contains `fund_id`, `as_of`, `source_url`, `file_sha256`, `top10_total_pct`, `amc_commentary`, and `holdings` array.

### FR-6: Diff Engine
- [x] **FR-6.1**: Pure Python, no LLM. Compare current month's snapshot against previous month's snapshot.
- [x] **FR-6.2**: Identify: `entered_top10`, `exited_top10`.
- [x] **FR-6.3**: Label as "entered top 10" / "exited top 10", NOT as "newly bought" or "sold".
- [x] **FR-6.4**: For holdings in both months: calculate weight delta (in percentage points) and rank change.
- [x] **FR-6.5**: Flag `significant` when |delta| >= fund's `significant_change_pp`.
- [x] **FR-6.6**: Use wording "weight increased/decreased", never "bought more".
- [x] **FR-6.7**: Output to `data/{fund_id}/{YYYY-MM}.diff.json`.

### FR-7: LLM Summary
- [x] **FR-7.1**: Provider pluggable via env var (`LLM_PROVIDER`). Default: OpenRouter free models, Gemini, Groq.
- [x] **FR-7.2**: Input: ONLY the diff JSON + AMC commentary. No external data.
- [x] **FR-7.3**: Prompt: "Use only the numbers provided. Do not add outside facts, predictions or advice."
- [x] **FR-7.4**: Output: 3-5 plain-language sentences summarizing the diff.
- [x] **FR-7.5**: Post-check: Extract every number in the LLM output and confirm it exists in the diff JSON. If any fabricated number found, discard output.
- [x] **FR-7.6**: Fallback: If API fails or post-check fails, generate a deterministic template summary.
- [x] **FR-7.7**: Pipeline must NEVER fail just because the LLM did.

### FR-8: Dashboard
- [x] **FR-8.1**: Home page: Grid of fund cards showing latest month, number of top-10 changes, biggest mover. Search/filter by AMC and category.
- [x] **FR-8.2**: Fund page: Top 10 table with weight, delta vs last month (green/red arrows), rank change. "Changes" panel (entered/exited, significant moves). AI summary clearly labeled. AMC commentary. Link to source factsheet.
- [x] **FR-8.3**: History chart: Weight over time for each current top-10 holding (Recharts area chart).
- [x] **FR-8.4**: Month selector to view past months.
- [x] **FR-8.5**: Responsive, dark mode, fast.
- [x] **FR-8.6**: Footer disclaimer: "Informational only. Not investment advice. Data from AMC factsheets; verify against the source."
- [x] **FR-8.7**: "Last updated" timestamp and data source on every page.

### FR-9: GitHub Actions Workflow
- [x] **FR-9.1**: Scheduled cron: Twice daily (6:00 AM IST / 00:30 UTC and 6:00 PM IST / 12:30 UTC) during days 3-20 of each month.
- [x] **FR-9.2**: Manual `workflow_dispatch` trigger available.
- [x] **FR-9.3**: A run with nothing new must exit cleanly with no commit.
- [x] **FR-9.4**: On success with new data: commit snapshots and diffs to `/data`, which triggers Vercel redeploy.

### FR-10: Backfill
- [x] **FR-10.1**: One-off script to ingest historical factsheets.
- [x] **FR-10.2**: Populates history so charts and diffs work from day one.
